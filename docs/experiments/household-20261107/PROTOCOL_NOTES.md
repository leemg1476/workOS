# 수행 중 기술적 변경과 해석 범위

- 보고서 작성 모델·출력 예산(3,500 tokens)·원천 가정·보고 window·작성 목적·평가 루브릭은 유지한다.
- 12회차 평가에서 2,400 tokens의 평가 응답이 끝나기 전에 잘려 SDK JSON 파싱이 실패했다. 12회차 보고서는 다시 쓰지 않고 저장된 동일 보고서를 재평가해 성공했다.
- 13회차 평가에서도 같은 EOF 오류가 발생하여 이후 평가 출력 상한만 4,000 tokens로 늘렸다. 채점 항목·배점·참조 산술은 바꾸지 않았다. 1~12회차의 원래 평가와 피드백 기록은 덮어쓰지 않는다.
- 새 평가 기록에는 `reviewer_max_output_tokens=4000`을 기록한다. 이전 기록은 2,400이었다.
- 네 체크포인트의 사후 블라인드 반복 채점은 모두 4,000 tokens 설정으로 실시한다. 작성 모델과 같은 모델의 별도 요청이며, 인간 전문가 평가 또는 생성 결과의 독립적 반복 표본이 아니다.
- 위 EOF 요청들의 사용량은 SDK 예외에서 획득하지 못했다. 집계 토큰 수는 저장된 성공 응답만 포함하며 전체 청구 사용량으로 주장하지 않는다.

- 19회차 자동평가가 공식 원문에 없는 전년도 감면 설명을 요구했다. Codex가 앞서 확인한 2025년8월·9월 공식 브리핑과 대조해, 별도 AI 원문 교정 의견을 work.agent_feedback에 기록했다. 기존 자동 점수·의견은 지우지 않았고 점수도 바꾸지 않았다. 20회차가 이미 기억을 고정했다면 21회차 이후부터 반영된다. 이 실험은 완전 무개입 자동 학습 실험이 아니며, 이 개입을 공개한다. 정확한 최초 반영 회차는 고정 memory snapshot으로 확인한다.

- 20회차 평가의 신선식품 부호 오류 경고는 원문 독해상 과잉 판정이었다. 보고서의 전년비2.5%, 전월비0.9% 하락에는 두 수치 모두 하락이 적용된다. Codex가 AI 교정 의견을 추가했으며 원 점수74와 경고는 변경하지 않는다. 자동 critical_errors는 확정 오류가 아니라 미검증 경고로 읽어야 한다.

- 30회차 자동 피드백이 다시 근거 없는 전년의 낮은 기저 설명을 요구했다. Codex가 앞의 동일 원문에 근거한 교정 의견을 추가했다. 기존 점수83과 보고서·자동피드백은 그대로 보존했다. 30회차 채점 뒤 개입이며 다음 기억 고정 시점부터만 반영된다.
