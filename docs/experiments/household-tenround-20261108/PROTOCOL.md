# 10회 실험 사전 계획

사용자 승인: 새 실험 전용으로 준비한 계산·필수항목·원문 인용을 적용하고, Codex가 근거를 확인한 피드백만 다음 회차에 반영하도록 명시적으로 승인했다. 기존42회 Task에는 적용하지 않는다.

목적: 수정한 지속 지식·원문 근거 경로에서 동일 보고서가 회차마다 실제로 어떻게 변하는지 관찰한다. 목표10회, 기간2025-09-01~09-30, 고정 A/B 가상 가구, 같은 모델·계약·루브릭을 사용한다. 매회 웹 검색을 허용하므로 검색 변동은 통제되지 않는다. 동일 사례 적응 순서1개이며 학습의 인과효과나 일반화를 입증하지 않는다.

실행: 전용 DB workos_tenround_20261108에서 수동 Task/Work/Run 경로를 사용한다. 일반 worker와 큐를 공유하지 않는다. 실제 gpt-6-luna 작성10회와 분리된 AI 평가10회를 예정하며, 실패·재시도가 있으면 숨기지 않는다. AI 평가는 참고 의견이다. 이전42회 점수와 새 점수를 직접 성능 비교하지 않는다(루브릭·구조가 바뀌었다).

초기 상태: 준비된 계산7개·필수항목3개를 첫 회차 전에 승인한다. 원문 인용은 같은 Task의 원문 스냅샷이 필요하므로 첫 회차 뒤 실제 읽은 원문과 연결하여 적용한다. 과거42개 보고서/의견은 주입하지 않는다. 준비된 초기 방법 자체는 과거 실험에서 얻었으므로 완전한 무경험 기준선은 아니다.

각 회차: 작성 → 결정론적 검사 → 실제 원문이 전달된 AI 평가 → Codex가 실제 보고서·원문·계산을 읽고 평가의 채택/기각 이유 기록 → 새로운 검토 교훈 최대1개를 승인 → 다음 회차. 승인 근거는 이번 사용자의 실험 한정 승인이다. Codex 검토를 인간 전문가 검토로 표시하지 않는다. 9회까지 최대9개 교훈을 더해 활성20개 한도를 지킨다. 10회 이후 새 작성은 하지 않는다.

분석: 매 회차 원문·점수와 차원별 평가·Run/Artifact/기억 해시·출처 읽기 상태·실제 승인 교훈을 보존한다. 보고서에는 전 회차 대비 추가/삭제/퇴행, 직전 피드백 반영 여부, 계산·구조 통과, 새로운 자료의 기여와 미확인을 정리한다. 변화 없음과 퇴행도 그대로 기록한다. 점수 상승을 내용 개선의 증거로 단독 사용하지 않는다. 대조군·맹검 사람 평가·반복 채점은 이10회 요청 범위에서 실행하지 않는다.

## 7회 완료 후 기록한 개입
생활비 산식을 설명하라는 승인 교훈이 반복해서 누락돼, 8회부터 이 피드백1개를 LESSON 대신 CHECKLIST로 저장한다. 나머지 계약·입력·루브릭·모델은 유지한다. 의미적 완결성을 보증하는 검사는 아니며, 프롬프트/출력 구조 개입을 포함하므로 순수 기억 효과로 해석하지 않는다. 6회 뒤 Codex 교훈의 단가 표현 오류를 철회·교정했고 이미 고정된7회 입력은 변경하지 않았다.

## 9회 완료 후 기록한 개입
CPI 비교 차이의 기준값을 검토한 뒤, 10회에는 새 교훈1개 대신 CALCULATION1개를 적용한다. 두 가구의 같은 기준지출200만원에 전체CPI2.1%를 적용한 증가액42,000원이다. 원 입력과 기존7개 계산은 유지하며, 새 숫자는 모델 계산이 아닌 Decimal AST 결과로 표에 추가한다. 간결성 보완 제안은 이번 마지막 활성 슬롯에서 시험하지 않는다.
